# Speekly

Минимальный PWA-каркас мессенджера на HTML, CSS и JavaScript.

## Запуск
1. Создайте таблицы в Supabase миграцией из проекта.
2. Заполните `config.js`: Project URL и publishable key (или legacy anon key).
3. Разместите содержимое репозитория на любом статическом хостинге с HTTPS.
4. Откройте сайт, зарегистрируйте аккаунт. Для создания диалога нужен UUID собеседника.

Секретный service-role key нельзя помещать в браузер.
